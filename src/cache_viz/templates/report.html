Automatic findings

    Misses (FILLs) per time window

    Each bar is one window of the range; its height is the number of FILLs, split into compulsory (first access to the block) and re-fills (the block was in the cache before and got evicted). Peaks = program phases with worse locality.

    Write-backs per time window

    EVICTs of dirty lines: each one is a block write to memory. Same windows as the chart next to it.

    Cumulative misses (warm-up)

    A compulsory curve that flattens = cache “warmed up” (working set loaded); a re-fill curve that keeps rising after that measures the steady-state cost of conflicts.

    Cache occupancy

    Valid and dirty lines over time (out of ). Low occupancy with many re-fills points to mapping conflicts, not lack of capacity.

    Heatmap: line × time

    Each cell counts the events of one cache line in one window. Persistently “hot” lines are conflict candidates; fully dark columns are miss bursts.

    Time distributions

    Log-scale histograms (each bucket doubles the previous one), in TIME units. The median and p90 summarize each distribution.

    Time between misses

    Time between consecutive FILLs (whole cache). Many small values = bursty misses, pressure on memory.

    Block lifetime

    From the FILL until the block leaves, by clean replacement or by write-back. Short life followed by a re-fill = thrashing.

    Time out of cache (reuse)

    From a block leaving until it comes back (re-fill). Quick returns = the block was evicted too early; more associativity would avoid them.

    Conflicts

    Tag replacement matrix

    Rows = tag that left; columns = tag that took its place (summed over all cache lines). A strong symmetric diagonal indicates pairs of memory regions competing for the same indices.

    Most contested pairs

    Per cache line: how many times one block evicted the other (both directions) and how many A→B→A ping-pongs happened.

    Per-line metrics

    Click a header to sort, and a row to filter the log and move the cursor to it. Occupancy = fraction of the range during which the line was valid.

    Cache comparison

    All caches loaded in this HTML, each over its full range. Useful to compare I-cache × D-cache, or two configurations/programs.
